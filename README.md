# jarios-parent

Parent POM comun para proyectos `local.jarios`.

Centraliza versiones de dependencias, versiones de plugins Maven y configuracion comun de Java/Maven para los proyectos Java de `contratacionmalaga`.

## Versión 1.0.14

Actualiza Logback a 1.6.4, Jackson a 2.22.3, Hibernate a 7.4.10.Final, jsoup a 1.23.2, Lombok a 1.18.48 y SLF4J a 2.0.20. Los proyectos consumidores solo deben actualizar la versión de este parent; no necesitan sobrescrituras locales.
